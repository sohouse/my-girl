# 本文档用于说明 02.tech-stack.md 中的语音功能 AI API 请求示例
1. 请求为XSS websocket请求，非http请求
2. X-Api-Request-Id header字段为随机生成UUID
3. 请求体的格式如下：
    a). 除prompt_text字段外，其余字段值为固定值
    b). prompt_text字段为用户输入的文本
    c). message具体值为
        1. 帧头固定 4 字节：11 14 10 00
        2. 后面跟 4 字节大端整数（JSON 长度）+ JSON 二进制。
        3. 例如：
            ```json
            {
                "input_id": "test_podcast",
                "action": 4,
                "prompt_text": "火山引擎",
                "use_head_music": false,
                "audio_config": {
                    "format": "mp3",
                    "sample_rate": 24000,
                    "speech_rate": 0,
                }
            }
            ```
            转为二进制后为：
