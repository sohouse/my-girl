# 该文档是对项目技术栈的硬性约束

1. 前端：React + TypeScript + Tailwind CSS + shadcn-ui + Next App Router
2. 后端：Node.js + Next.js API Route 内嵌Hono
3. 数据库：Neon Serverless Postgres
4. 部署：Vercel
5. 数据与schema校验：Zod
6. 用户注册与登录：Better Auth
7. 语音功能：豆包 volc.service_type.10050 API
8. 文生图功能：ark doubao-seedream-5-0-260128 API
9. 文字对话功能：minimax MiniMax-M2.7 API
10. 邮件发送：resend API
11. ORM: - Drizzle ORM + Drizzle schema 与 migration 工具链
12. 存储：CloudFlare R2 Store
13. 人机验证：CloudFlare Turnstile

## Zod 负责：
- 请求体结构校验
- 查询参数校验
- 表单输入的运行时验证
- 前后端共享的数据 shape 声明
- 将“不可信输入”在进入业务逻辑前尽可能收口

1. doubao-seedream-5-0-260128 文生图功能
``` curl
  curl https://ark.cn-beijing.volces.com/api/v3/images/generations
```
