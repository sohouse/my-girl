# 项目介绍

<br />

## 该项目是一个虚拟女友项目，用户可以使用此项目达到虚拟陪伴目的。

<br />

## 该项目的最终形态是一个全栈web项目，包含用户使用流程和一个后端管理系统。

<br />

### 用户界面

1. 用户登录后使用功能
2. 起始页提供四个预设人格的女友可供选择，并且提供通过语言描述自定义女友及其头像的能力。
3. 选择角色后进入对话，聊天内容根据角色一个好感度并依赖AI给出冷漠或者热情的不同回答
4. 文字部分的回答可以通过AI API转为声音播放，播放时的语气变化要符合人设及上下文
5. 角色的回答可以根据上下文理解后发送图片，如果发送图片为自拍则需要根据预设人基准照片二次生成
6. 角色有记忆功能，可以记住对话中的重要内容
7. 与角色的对话存储在数据库中，可以按照时间查看并继续对话
8. 角色可在重要节日或者重要日期或者定时主动向用户的邮箱发送消息
9. 可以随时分享与角色的对话，生成的分享图中需要包括网址和手动选择的对话，分享卡片要有设计感

### 后端管理系统

1. 必须有一个统一的后台入口管理界面
2. 可以查看和维护接入AI API的接口断点和API KEY
3. 可以查看所有注册用户的名称、邮箱地址和用户的自定义角色
4. 可以管理预设角色信息，预设角色可维护信息必须包含角色人设、成长背景、说话语气、口头禅、行为动机
5. 可以自定义用户邮件发送功能
